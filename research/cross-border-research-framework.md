# 第一部分：把你的框架改对

## 1.1 你原来的问题清单

你列的 19 个问题按原顺序是：选国家 → 为什么值得做 → 网络普及率 → 消费力 → 购买需求 → 退货意愿 → 哪些平台支持 → 需要准备什么 → 是否支持无库存 → 时效 → 选什么商品 → 具体流程 → 国际银行卡 → 汇率 → 合规 → 启动资金 → 多少天有收益 → 哪个平台上架 → AI 客服。

**这份清单本身是合格的，问题出在顺序。**它是"从机会往下推"，而机会层是最贵的研究——查十个国家的消费力要花几天，而其中九个可能在第一步就被主体资格挡住了。

## 1.2 正确的顺序是倒着排除

**排除比选择便宜。**每一层都是硬门槛，过不了这一层，下面所有研究都是白做的。

```
第 0 层  主体与收款   我能不能合法开店、合法把钱收回来？
第 1 层  平台准入     哪些平台接受我这种主体？
第 2 层  履约可行性   不压货能不能满足这个平台的发货时效？
第 3 层  单位经济     一单到底赚不赚钱（含拒收率和广告费）？
第 4 层  国家与品类   ——你原来的清单从这里才开始
第 5 层  第一单来源   自然流量还是必须投广告？CAC 是否低于毛利？
第 6 层  积累与退出   90 天之后我手里还剩下什么？
```

本次调研证明了这个顺序的必要性：**第 0 层和第 1 层就淘汰掉了绝大多数平台**（见第二部分 2.2），根本轮不到比较"沙特和摩洛哥哪个消费力高"。

## 1.3 你缺的六项（每一项都能单独让整件事死掉）

### 缺项一：主体资格 —— 比选国家更靠前

你完全没问。而 2026 年的现实是：**纯个人（只有身份证）能入驻的主流平台只剩 Temu 个人店和 eBay。**Shopee、Lazada、速卖通、TikTok Shop、SHEIN、亚马逊全部要营业执照。Lazada 自 2025-06-25 起连个体工商户都不接受。

这一条不解决，后面选哪个国家都是空谈。

### 缺项二：钱怎么回来，以及天花板在哪

你问了"是否需要国际银行卡支付"和"汇率"，但问的是**买家怎么付钱**——那是平台的事，不是你的事。

你真正该问的是：**平台的钱怎么到你的国内银行卡，中间有几道关，个人主体有没有额度天花板。**答案见 2.3，结论是好消息，但依据和网上流传的不是同一条。

### 缺项三：COD 拒收率 —— 不是"退货意愿"

你问了"退货意愿"，方向对，层次错了。

在中东、非洲这些 COD（货到付款）为主的市场，杀死你的不是退货，是**拒收**：买家下单时一分钱没付，货送到门口拒收，你已经付了双程运费，一分钱收不到。这甚至不算一笔失败的交易——它从来没成交过，但成本全在你这边。

实测数据见 2.6，中小卖家平均签收率 60%–65%，最差区域不及 35%。这一条直接决定了你的毛利率准入线。

### 缺项四：现金流周期 ≠ 启动资金

你问了"启动资金"，那是一次性投入。真正会转不动的是**回款账期**：货发出去了，平台要等 30、60 甚至 90 天才打款，这期间你的钱被占着。

**不压货 ≠ 不占资金。**代发要先垫付货款和运费，回款滞后。你有 1 万元，真实周转能力可能只有一两千元的在途资金。这意味着**爆单对你是风险不是好事**——垫不起货款就得延迟发货，延迟发货就触发平台罚分。

2026 年这一层在集体恶化，见 2.5。

### 缺项五：这个机会为什么还在

你问"哪些国家值得做"，但没问反过来的那句：**如果这么好，为什么还没被做满？**

任何看起来空白的市场，要么有隐藏的坑（清关、外汇管制、拒收率），要么规模太小养不活人。**先问坑在哪，再问机会在哪**——这样你研究十个市场的成本会降一个数量级。

中东就是典型例子：它看起来是蓝海，不是因为没人发现，是因为发现的人被 35%–40% 的拒收率打出去了。

### 缺项六：退出成本与单次失败的敞口

封店那天，你有多少钱在平台账上？多少货在路上？多少保证金冻着？

这个数字决定了单次失败会不会让你直接出局。一个有全职工作的人，可以承受"这个月白干"，不能承受"三个月的本金锁在冻结账户里半年"。

### 附带两项小的

**时区与客服响应。**你有全职工作。中东时区差 5 小时，拉美差 12 小时，而客服响应时效是平台考核指标。这和"每天 3–4 小时"直接冲突。

**能不能积累。**90 天跑通之后，第 91 天你手里有什么——店铺权重？供应商关系？客户名单？如果什么都不剩，它就是打工，只是换了个地方。

## 1.4 我的研究方法（你问的"你会怎么做"）

1. **先找否定条件。**不问"这件事怎么做成"，先问"哪一条能单独让它死"。找到了就先验证那一条，省掉后面全部工作。
2. **只认官方原文。**二手内容站之间互相抄，而且抄的常常是已经废止的法条（本次就抓到一例，见 2.3）。
3. **主动找失败者。**成功案例是幸存者偏差的产物。要找亏钱的、封店的、退出的。
4. **单位经济算到最小单元。**不看"市场规模 XX 亿"，看"这一单我到手多少"。
5. **查不到就写"无法确认"。**不用常识补全。本报告末尾有完整的无法确认清单。

# 第二部分：基础设施层调研结果（2026-09）

## 2.1 三个改变结论的发现

1. 网上大量文章引用的"个人跨境电商结汇不占 5 万美元额度"的法规依据（汇发〔2020〕11 号）**已于 2025-10-28 被汇发〔2025〕47 号全文废止**。结论依然成立，但现行依据换成了汇发〔2020〕14 号第六十六条。
2. **纯个人可入驻的主流平台，2026 年只剩 Temu 个人店（类目受限）和 eBay。**

**废止的**：《国家外汇管理局关于支持贸易新业态发展的通知》（汇发〔2020〕11 号）——网上引用最多的那条出处——已于 **2025-10-28 被《汇发〔2025〕47 号》全文废止**。

**现行有效的**：《经常项目外汇业务指引（2020 年版）》（汇发〔2020〕14 号）第六十六条第（二）项：

**结论：5 万美元是"凭身份证即可办理"的便利化额度，不是收汇上限。**走持牌收款机构的合规申报路径，按实际交易金额办理，理论上不撞天花板。你的目标规模（年流水 10–30 万人民币）几年内都碰不到这条线。

另外：年度货物贸易收汇累计低于 20 万美元的小微跨境电商企业可免于名录登记；自 2026-01-01 起单笔人民币 5000 元/外币等值 1000 美元以上跨境汇款需核实汇款人信息（是"核实"不是"限制"）。

### 合规边界：真实案例，不是泛泛而谈

**允许的做法**：本人身份开持牌收款机构账户 → 平台货款进账 → 机构按交易电子信息完成外汇申报 → 结汇到本人同名银行卡。法律依据现行有效。

**会出事的做法**（每条都有案例对应）：

外汇局河北省分局公布的[行刑反向衔接典型案例](https://www.safe.gov.cn/big5/big5/www.safe.gov.cn/hebei/2025/0512/2357.html)（**A**）：陈某某在未实际从事外贸的情况下，以本人及亲属名下个体工商户开立多个个人外汇结算账户，以虚构贸易形式提供给地下钱庄接收外汇，**涉案 5.6 亿元，获利 76 万元**。两名仅出借账户的亲属虽不起诉，仍因违反《境内外汇账户管理规定》第四十四条（**个人外汇结算账户不得出借、串用或者转让**）被行政处罚。

## 2.4 海关监管代码与"无票免税"：对你基本无效

| 代码 | 场景 |
|---|---|
| **9610** | B2C 直邮出口，清单核放汇总申报，不支持退税但可合规收汇 |
| **1210** | 保税跨境电商，先入综保区保税仓，入区即退税 |
| **9710** | 跨境电商 B2B 直接出口 |
| **9810** | 跨境电商出口海外仓（含 FBA），2026 年起可"离境即退税" |

**但你实际上不会用到任何一个。**走 Shopee/TikTok Shop 官方物流时，包裹交给平台国内中转仓，报关由平台/物流商统一处理，**卖家侧不出现报关单**。

这意味着综试区"无票免税"（[财税〔2018〕103 号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202404/content.html)，A 级，政策仍有效）的三个条件里，"出口货物通过综试区所在地海关办理电子商务出口申报手续"这条你做不到。

**加上你月销 10 万以下本就免增值税——这项政策对你的真实价值接近于零。**

**一句话**：买通道和数据，自己写算账和告警。

## 2.11 把目标翻译成真实工作量

这一节比上面所有数据都重要。

前述 C 级自述里，做到"月销 3000 美金"时净利是"三四千人民币"——**恰好就是你的目标**。反推：

```
月净利 3,000–5,000 元 ≈ 月流水 2 万–3.5 万人民币 ≈ 日均十几到几十单
按每天 3 小时 × 每月 90 小时计算 → 时薪约 44 元
```

而按 DTS 规则，那是每天下班后要处理几十个订单的发货、客服、退货，**且不能拖过第二天 14:00，周六也算履约日**。

**这不是"低目标"，这是一份需要每天稳定投入、不能请假的第二份工作。**前 3–6 个月收入可能为零甚至为负。

把它当"每月多赚 4000 元"评估会严重低估投入；当"一份时薪约 44 元、前半年无薪的兼职"评估，才是对的。

## 2.12 由此得出的一个结构性判断

把 2.5（DTS）、2.7（现金流）、2.11（工作量）叠在一起，会得到一个比任何单条都重要的结论：

> **"有全职工作 + 一件代发 + 平台严格发货时效"这三者在结构上互相冲突。**

这不是说跨境电商不能做，而是说**能做的模式被这个冲突筛掉了一大半**。剩下的出路只有三条：

1. **把履约责任交出去**——Temu 全托管（平台定价、运营、物流、售后，你只供货）。代价：学不到运营，没有客户资产，是纯供应商角色。
2. **用预售换时间**——Shopee 预售 DTS 4–10 个发货日。代价：转化率下降。
3. **选没有物流的品类**——虚拟/数字/服务类。代价：跳出了"跨境电商"这个框，变成另一件事。

**第三部分（国家 × 平台市场层）的调研，应当在这三条通路的约束下进行**，而不是先选国家。
